# 星海未眠

为「星海之间」创作的原创器乐配乐。旋律与和声以柔和钢琴为主，加入暖垫、十二次稀疏的星铃和立体声混响；没有使用已有歌曲、采样录音或外部音乐服务。

- 长度：117.49 秒；68 BPM，4/4，D 大调，32 小节。
- 结构：8 小节主题 → 8 小节变奏 → 8 小节高音区中段 → 8 小节主题回归。
- 音色：程序合成的毡音钢琴、缓慢漂移的铺底和玻璃铃音。
- 首尾：都落在 D 上，开头淡入、结尾自然衰减，循环之间保留短暂呼吸；不是无缝环境采样循环。
- 交付：96 kbps 立体声 MP3，约 1.41 MB；实际响度 −19.45 LUFS，真峰值 −5.88 dBTP，无削波。

播放文件位于 `dist/audio/starsea-awake.mp3`，播放器控制在 `dist/music.js`。浏览器限制有声自动播放时，首个用户交互会尝试开始播放。

## 重新生成（可选）

站点运行不需要 Python。只有重新合成音轨时才需要 Python 3、NumPy、SciPy 与 FFmpeg：

```bash
python tools/compose_soundtrack.py
```

固定随机种子确保乐谱与音色合成可重复。脚本在 `music/generated/` 中生成无损母带、MP3、15 秒试听和检测数据；该目录已加入 Git 忽略列表。替换网站音轨时，将生成的 `starsea-awake.mp3` 复制到 `dist/audio/`。
