# 星海之间 · Starsea

独立的实时 3D 星海场景。采用原生 JavaScript 和 WebGL 2，无外部运行时依赖、图片或 CDN 请求。

天空使用三维分形噪声构成星云与尘埃层，透视射线与湖面相交，湖面法线由多组波浪与点击涟漪生成。星云、星空与流星共用世界坐标，水面按反射方向重新采样天空。发光微粒使用三维坐标独立投影。

星云沿天球持续流动，叠加缓慢的分层气流，使云团边缘舒展；颜色与细纹共用流动坐标，星点独立保持位置。流星沿大圆弧快速划过，亮核、细尾与气体余辉各自衰减。尾迹按星头经过每一点的时间计算，星头燃尽后仍留在原位逐渐淡去，天空和水面共用同一套动态。动画时间独立于视角输入的步长，较低帧率下仍保持正常速度。

操作：拖动或方向键进行水平、垂直无限制 360° 旋转（允许翻转）；点击湖面产生涟漪；滚轮、双指开合、加减按钮或键盘 +/− 在 0.75–16 倍之间缩放；点击倍率恢复 1 倍；“唤起流星”触发 24 颗流星的连续流星群；空格暂停；指南针按钮或 Home 回到初始视角；沉浸模式可用退出按钮或 Escape 返回。

缩放修改透视视野，并逐像素重新求值。放大时按连续细节层级引入固定世界频率的星云细纹和微波纹；新增噪声为零均值，并按像素覆盖范围过滤。星点亮核按屏幕像素控制大小。场景没有被放大的位图纹理，也不对旧帧执行图像拉伸；最终输出仍受实际渲染像素和浮点精度限制。

默认使用高清画质，并提供超清画质、自动、流畅模式。自动模式会在持续低帧率时适度降低分辨率，并在性能恢复后逐步恢复；手动高清和超清保持所选分辨率。移动端支持触摸拖动。流星覆盖整个天空，每隔约 0.9–2.2 秒自动生成一颗，最多同时显示 12 颗（包含消散中的尾迹）。流星独立时钟为原速的 60%，星头与尾迹一起放慢；初始画面仅出现一颗流星。页面不可见时停止绘制；遵循系统减少动态效果偏好。启动需要 WebGL 2。

`dist/` 为完整可直接托管的静态站点目录，入口为 `index.html`。

## 纯前端与部署

本项目仅包含 HTML、CSS、JavaScript 和 GLSL 着色器。全部动画在访问者浏览器内运行，无服务器进程、数据库、API、密钥、环境变量或外部运行时依赖。`dist/` 中的三个文件同时也是完整源码，无需编译或安装依赖。

### EdgeOne Pages

导入 GitHub 仓库时，将仓库根目录作为项目根目录；选择普通静态站点对应的框架预设（Other / 其他），发布目录设为 `dist`。本仓库的 `edgeone.json` 已指定 `outputDirectory: "./dist"`。不需要 npm 安装或构建步骤。

也可以直接上传 `dist/` 目录中的内容；上传后的站点根目录应直接包含 `index.html`、`scene.js` 和 `style.css`，不要让访问路径多一层 `dist/`。

官方配置说明：https://pages.edgeone.ai/document/edgeone-json

### 本地预览

在项目根目录运行：

```bash
python -m http.server 8080 --directory dist
```

然后打开 http://localhost:8080 。Windows 如使用 Python 启动器，可把 `python` 换成 `py`。需要支持 WebGL 2 且开启硬件加速的现代浏览器。

### 文件说明

| 文件 | 作用 |
| --- | --- |
| `dist/index.html` | 页面结构和交互控件 |
| `dist/style.css` | 全屏布局和响应式样式 |
| `dist/scene.js` | WebGL 场景、着色器、星云、流星、镜湖和交互逻辑 |
| `edgeone.json` | EdgeOne 静态发布目录配置 |

最新行为：流星使用 60% 的动画速度，自动生成间隔约 0.9–2.2 秒；初始出现一颗流星；保留动态星云、镜湖反射、360° 旋转和 0.75–16 倍缩放。
