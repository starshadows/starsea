# 星海之间 · Starsea

独立的实时 3D 星海场景。采用原生 JavaScript 和 WebGL 2，将星云纹理缓存与实时星点、流星和水面结合。星云纹理由浏览器本地生成，无外部运行时依赖、图片下载或 CDN 请求。

天空使用三维分形噪声构成星云与尘埃层，启动时默认生成六个 1024×1024 面组成的立方体纹理，缓存计算完成的星云颜色和密度。每帧用轻量流场改变采样方向，使云团缓慢流动；天空和水面倒影复用同一份星云缓存。透视射线仍与湖面实时相交，湖面法线由多组波浪与点击涟漪实时生成。星点、流星和发光微粒保持独立实时绘制。

流星沿大圆弧快速划过，亮核、细尾与气体余辉各自衰减。尾迹按星头经过每一点的时间计算，星头燃尽后仍留在原位逐渐淡去，天空和水面共用同一套动态。动画时间独立于视角输入的步长，较低帧率下仍保持正常速度。

操作：拖动或方向键进行水平、垂直无限制 360° 旋转（允许翻转）；点击湖面产生涟漪；滚轮、双指开合、加减按钮或键盘 +/− 在 0.75–16 倍之间缩放；点击倍率恢复 1 倍；“唤起流星”触发 24 颗流星的连续流星群；空格暂停；指南针按钮或 Home 回到初始视角；沉浸模式可用退出按钮或 Escape 返回。

缩放修改透视视野。高倍观察时，按当前视角额外生成局部星云纹理，包含对应倍率的细纹；视角或倍率超出缓存覆盖范围后按需补绘，避免只放大初始全景纹理。星点亮核仍按屏幕像素控制大小，微波纹和反射方向继续实时计算。这种混合方式允许星云细节轻微柔化、云团运动与原先逐像素生成版本有所变化；它不保证逐帧或逐像素完全一致。星点、流星、水波和涟漪的实时细节不改为缓存图片。

缓存优先使用 RGBA16F 浮点纹理；设备不支持时改用经过编码的 RGBA8 纹理。分配失败会尝试 512 或 256 像素的面尺寸；缓存初始化仍失败时，自动回退到完整的程序化星云着色器。缓存生成会增加启动时的 GPU 工作和显存占用，高倍视角的局部补绘也有一次性开销。

默认高清画质按设备原生像素密度绘制，取消手机原先的 2 倍像素上限；超清模式在低于 3 倍的设备上增加最多 25% 的采样密度，高于 3 倍的设备仍保留原生密度。两者仅受 WebGL 硬件尺寸限制。自动模式会在持续低帧率时适度降低分辨率，并在性能恢复后逐步恢复；流畅模式使用较低的像素预算。移动端支持触摸拖动，画布跟随实际可视区域、横竖屏和屏幕像素密度变化。流星覆盖整个天空，每隔约 0.9–2.2 秒自动生成一颗，最多同时显示 12 颗（包含消散中的尾迹）。流星独立时钟为原速的 60%，星头与尾迹一起放慢；初始画面仅出现一颗流星。页面不可见时停止绘制；遵循系统减少动态效果偏好。启动需要 WebGL 2。

性能优化的主要方式是复用已经绘制完成的星云，减少天空和湖面倒影每帧重复进行的多层噪声计算。空星格和贡献已为零的水面效果提前结束；镜头与波浪公共参数每帧只计算一次，流星只遍历实际存活的条目。镜头阻尼按真实经过时间计算，避免低帧率时拖动响应额外变慢。提高原生分辨率仍会增加 GPU 工作量，实际帧率和缓存收益取决于设备、视角及倍率。

`dist/` 为完整可直接托管的静态站点目录，入口为 `index.html`。

## 纯前端与部署

本项目包含 HTML、CSS、JavaScript、GLSL 着色器，以及随站点一起托管的原创 MP3 配乐。全部动画与纹理生成在访问者浏览器内运行，无服务器进程、数据库、API、密钥、环境变量或外部运行时依赖。`dist/` 包含可直接部署的完整源码与资源，无需编译或安装依赖。

### 原创配乐《星海未眠》

为星云与镜湖场景创作的器乐配乐，以轻柔钢琴、温暖铺底和稀疏铃音构成旋律与和声。音频随页面托管，不依赖音乐平台、第三方链接或在线生成服务。

页面默认尝试以较低音量循环播放。浏览器允许有声自动播放时直接开始；如果浏览器拦截，首次点击、拖动结束或按键后开始，并显示“轻触聆听”的提示。网页无法强制绕过浏览器的自动播放策略。右上角的音乐按钮可开关配乐，并在本设备记住选择；沉浸模式下左下角保留音乐按钮。切换到后台时暂停，回来后按原来的开关状态恢复。音乐开关独立于场景动画暂停。

音乐为原创旋律和程序合成音色，无采样歌曲或外部录音。可选的离线作曲脚本位于 `tools/compose_soundtrack.py`，仅用于重新生成音频，不参与站点运行。相关说明见 `music/README.md`。

### EdgeOne Pages

导入 GitHub 仓库时，将仓库根目录作为项目根目录；选择普通静态站点对应的框架预设（Other / 其他），发布目录设为 `dist`。本仓库的 `edgeone.json` 已指定 `outputDirectory: "./dist"`。不需要 npm 安装或构建步骤。

也可以直接上传 `dist/` 目录中的全部内容；上传后的站点根目录应直接包含 `index.html`、`scene.js`、`nebula-cache.js`、`music.js`、`style.css` 和 `audio/` 文件夹，不要让访问路径多一层 `dist/`。更新已有站点时也要一并上传 `nebula-cache.js` 和音频资源，保留完整目录结构。

官方配置说明：https://pages.edgeone.ai/document/edgeone-json

### 本地预览

在项目根目录运行：

```bash
python -m http.server 8080 --directory dist
```

然后打开 http://localhost:8080 。Windows 如使用 Python 启动器，可把 `python` 换成 `py`。需要支持 WebGL 2 且开启硬件加速的现代浏览器。

### 文件说明

| 文件 | 作用 |
| --- | --- |
| `dist/index.html` | 页面结构和交互控件 |
| `dist/style.css` | 全屏布局和响应式样式 |
| `dist/scene.js` | WebGL 场景、着色器、星云、流星、镜湖和交互逻辑 |
| `dist/nebula-cache.js` | 星云立方体纹理生成、局部高倍补绘、纹理格式与尺寸回退 |
| `dist/music.js` | 自动播放尝试、交互解锁、音乐开关与后台暂停 |
| `dist/audio/starsea-awake.mp3` | 原创循环配乐《星海未眠》 |
| `tools/compose_soundtrack.py` | 可选的离线作曲与音频生成脚本 |
| `edgeone.json` | EdgeOne 静态发布目录配置 |

最新行为：星云使用本地生成的纹理缓存与流场动画，高倍观察按需补绘局部细节；保留实时星点、流星、镜湖反射、360° 旋转和 0.75–16 倍缩放。
